# EN-14 La matriz de cada fase, con una sola tabla de historias y una de habilitadores

> **Estado:** ✅ cerrada (las dos tareas `[DOC]` ejecutadas el 2026-10-31, una por commit; las opciones recomendadas de la propuesta del mismo día).

| Campo | Contenido |
|---|---|
| Para | Que la matriz de cada fase tenga exactamente dos tablas, una de historias y una de habilitadores, sin separar «Abiertas» de «Cerradas» |
| Porque | Hoy cada tipo se parte en dos tablas con columnas distintas y una historia cambia de tabla al cerrarse, aunque el estado ya dice si está abierta o cerrada |

## Criterios

| Dado | Cuando | Entonces |
|---|---|---|
| La matriz de una fase | Se genera | Tiene un título por tipo, `## Historias` y `## Habilitadores`, y bajo cada uno una sola tabla; no hay subsecciones «Abiertas» ni «Cerradas» |
| Las historias de una fase | Se listan | Una sola tabla con las columnas ID, Historia, Épica, Estado, API, Web, Cambios de producto, Tareas y Fechas y tiempo, para historias abiertas y cerradas por igual |
| Los habilitadores de una fase | Se listan | Una sola tabla con las columnas ID, Habilitador, Ligado a, Estado, Tareas y Fechas y tiempo |
| Una fila de una historia o un habilitador cerrado | Se escribe | Su columna «Fechas y tiempo» dice «inicio → cierre · tiempo», y la de uno abierto, «inicio → en curso · tiempo» |
| Las filas de una tabla | Se ordenan | Por ID, sea cual sea su estado, de modo que una historia no cambia de sitio al avanzar |
| Un tipo sin filas en la fase (la fase 1 no tiene habilitadores) | Se genera la matriz | Conserva su título y una línea «_No hay habilitadores en esta fase._» en vez de la tabla |
| El índice de fases del README de historias | Se genera | Sigue mostrando «n abiertas · m cerradas» por fase y tipo |
| Un documento vivo | Describe la matriz | No habla de «Abiertas» ni «Cerradas» como tablas; los congelados y los habilitadores cerrados conservan su texto |

## Listo cuando

Las matrices de las fases 1 y 2 tienen solo las dos tablas por tipo, ordenadas por ID y con las mismas columnas para filas abiertas y cerradas, el índice de fases conserva sus conteos, ningún documento vivo habla de las subsecciones y pasan el comprobador, las suites de `scripts/` y las pruebas de convenciones de documentos.
