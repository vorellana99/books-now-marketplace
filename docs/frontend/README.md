# LibroYa: guía del frontend

Pendiente. Esta carpeta es para la guía de `apps/store-web`. Se apoya en:

- [`../product/`](../product/README.md): **fuente de información del producto** (historias, reglas de negocio, pantallas, textos y decisiones abiertas). La guía del frontend cita sus identificadores (`HU-nn`, `RN-nn`, `PA-nn`, `DP-nn`) en lugar de repetirlos.
- [`../api-contrato.md`](../api-contrato.md): rutas, respuestas, errores y formato de montos, comunes con el backend.

Antes de escribirla hay que resolver las preguntas abiertas de [`../product/09-decisiones-y-preguntas.md`](../product/09-decisiones-y-preguntas.md) que afectan al stack, en especial DP-04 (carrito), DP-07 (total antes de pagar), DP-11 a DP-16 (sesión, intención tras entrar, direcciones y clave de idempotencia).
